# Velas Ana — Catálogo Web

Catálogo web minimalista para **Velas Ana**, emprendimiento de velas artesanales de cera de soja. Diseñado con una estética editorial limpia, responsivo y pensado para exhibir productos por categoría con vista de detalle.

## Características

- **Catálogo filtrable:** Navegación por categorías (*Todos*, *Set*, *Individuales*, *Souvenirs*, *Esculturas*).
- **Vista de detalle (Modal):** Ficha ampliada de cada vela con descripción completa sin recorte de texto.
- **Diseño responsivo:** Adaptado a escritorio y dispositivos móviles con paleta cálida y tipografía editorial.
- **Enfoque seguro:** Catálogo de exhibición sin exposición directa de datos personales de contacto.

## Tecnologías

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Oxlint**

## Instalación y uso local

```bash
# Clonar el repositorio
git clone [https://github.com/faustotica/velasAna.git](https://github.com/faustotica/velasAna.git)

# Entrar al directorio
cd velasAna

# Instalar dependencias
npm install

# Iniciar servidor de desarrollo
npm run dev
